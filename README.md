# everywright.com

The website for Everywright, a Toronto web studio.

## Start building with Claude Code

1. Open this folder (`everywright-site`) in Claude Code.
2. Type: **Read CLAUDE.md and the docs folder, then build the site.**
3. Claude Code will ask you how you want the contact form to work. Pick one, then let it finish.

## What's in here

- `CLAUDE.md`: instructions Claude Code reads automatically
- `docs/brief.md`: the business, the offer and the packages
- `docs/content.md`: all the words on the website
- `docs/brand.md`: name, voice, colours and look
- `docs/deploy.md`: how to put the site online at everywright.com
- `site/`: the website itself (Claude Code builds it here)

## Changing the website later

Edit the words in `docs/content.md`, then ask Claude Code to update the site to match. Or ask Claude Code directly, for example "change the Growth price to $900".
